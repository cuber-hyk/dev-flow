Skill

dev-exploratory-review

开放式风险发现。适合问题位置未知、需要先建立项目地图和风险地图的审查。

流程输出状态产物

内部流程

Map
Project map->Risk map
Probe
Project Mapper->Risk Prober->Adversarial Verifier
Judge
只报告真实失败路径->给出后续路由

输出格式

输出包含 scope、project map、risk map、review passes、findings、non-findings、recommended probes 和 next action。持久报告使用 audit 模板。

Finding 状态

与 /dev-audit skill 一致，只使用 open、planned、resolved、verified。主观风格偏好、命名偏好和无失败路径的猜测不应成为 finding。

生命周期

非平凡探索报告写入 docs/audits/ 并保持 active，直到所有 findings verified，或 resolved 且 Closeout 说明接受风险、不处理、不可复现，或完整转入 active plan。
