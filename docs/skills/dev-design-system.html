dev-design-system

维护项目级、持续演化的 UI 设计契约：确认规则写入 DESIGN.md，精确数值写入 design-tokens.json，并约束语义组件复用。

工作模式事实来源复用规则检查 Gate

工作模式

initialize 在代表性 UI 经用户确认后建立首版规范；update 沉淀任务中新确认的可复用规则；check 检查实现是否遵守规范。

事实来源

DESIGN.md 管理设计意图、使用规则和交互模式；design-tokens.json 管理精确数值；共享组件和 Storybook 管理可执行行为与视觉状态。

语义复用

复用依据是场景含义和行为，而不只是外观。相同语义场景必须优先复用现有组件或交互模式，内容和业务回调可以不同。

检查 Gate

UI 任务在审核前检查 DESIGN.md、Token、共享组件、响应式、视觉和可访问性；只有确认后的通用规则才更新设计契约。
