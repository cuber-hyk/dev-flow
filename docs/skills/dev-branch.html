Skill

dev-branch

在隔离分支中完成实现、验证和审查前收尾。它是闭环执行技能，但不会自动提交、合并或推送。

流程门控输出生命周期

固定执行顺序

Work
确认 dirty worktree->创建任务分支->实现->验证
Closeout
Changelog Gate->Distill Gate->Check Gate->Independent Review->Approval Review

门控说明

Changelog gate 判断是否需要调用 /dev-changelog skill；Distill gate 判断是否需要调用 /dev-distill skill 更新长期知识、ADR、plan/audit 生命周期；Check gate 在文档或生命周期产物变化后运行验证；Independent Review 仅在有价值且可安全委派时使用只读子 Agent，否则执行同形状的 manual review。主 Agent 必须复核所有 finding，任一 gate blocked 时不得进入提交或合并审批。

输出格式

审查前输出必须包含 branch、existing changes、changes made、verification、changelog gate、distill gate、check gate、subagent review gate、review 和 waiting for approval。合并后才使用 after merge 输出。

生命周期

来自 audit 的任务需要更新 finding 的 Owner Plan、Branch/Commit、Verification 和 Status。一个 audit 可以驱动多个 plan/branch；只修复部分 finding 时 audit 保持 active。
