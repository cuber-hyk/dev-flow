Skill

dev-orient

低噪声进入仓库上下文。它帮助 Agent 找到事实源、代码入口和文档目的地，但不制定计划、不审查、不实现。

流程输出产物下一步

内部流程

先读取 AGENTS、CONTEXT、context-map 和相关 capability 文档，再按任务关键词定位代码入口。只读与当前任务有关的文件，避免全仓库漫游。

输出格式

输出包含 loaded context、relevant entry points、fact sources、artifact destinations、dirty worktree visibility 和 recommended next skill。

技能产物

通常只在对话中输出上下文地图，不创建持久文档。若发现缺失结构，应建议 /dev-init skill；若发现生命周期问题，应建议 /dev-check skill。

后续路由

目标模糊时进入 /dev-brainstorm skill；目标明确但非平凡时进入 /dev-plan skill；需要发现问题时进入 /dev-audit skill；已有清晰计划时进入 /dev-branch skill。
