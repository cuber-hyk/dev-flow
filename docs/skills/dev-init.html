Skill

dev-init

初始化 Dev Flow 的最小文档骨架。它只补齐缺失结构和模板，不替项目推断完整业务知识。

流程输出产物生命周期

内部流程

Inspect
读取现有 AGENTS/CONTEXT/docs->识别缺失结构
Create
运行 init CLI->只创建缺失文件
Verify
检查路径存在->建议 /dev-check skill

输出格式

最终输出说明初始化目标、创建的路径、保持不变的路径、验证结果和下一步。若目录已完整，输出应明确说明没有创建新文件。

技能产物

可能创建 AGENTS.md、CONTEXT.md、CHANGELOG.md、docs/ai/context-map.md、docs/plans/、docs/audits/、docs/capabilities/、docs/adr/ 及模板。

生命周期

dev-init 不关闭 plan/audit，也不归档文档。初始化完成后的健康检查交给 /dev-check skill；具体任务上下文交给 /dev-orient、/dev-plan 或 /dev-audit skill。
