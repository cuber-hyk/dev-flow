Skill

dev-distill

把完成后的事实沉淀到长期文档，并关闭 plan/audit 等过程产物。它不重新规划、不重新审查、不重新实现。

流程关闭规则输出ADR Gate

内部流程

Classify
识别长期事实->选择 CONTEXT/capability/context-map/ADR/test
Close
Plan Closeout->Audit Closeout->ADR Gate
Verify
运行相关验证->建议 /dev-check skill

关闭规则

plan 只有在所有非延后步骤为 done、没有 blocked、验证已记录且关联 audit finding 已更新后才可归档或删除。audit 只有在所有 findings verified，或 resolved 且 Closeout 说明接受风险、不处理、不可复现，或完整转入 active plan 后才可归档或删除。

输出格式

输出包含 durable updates、plan closeout、audit closeout gate、ADR gate、verification 和 next step。若发现 open/planned finding、未验证 resolved finding 或缺少 closeout，应报告 blocked 并保持 audit active。

ADR Gate

当任务改变长期架构、事实源、数据迁移策略、跨模块规则、算法政策或重大取舍时，dev-distill 必须主动判断是否需要 ADR；普通 bug 修复和一次性审查结论不写 ADR。
