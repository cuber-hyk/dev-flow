dev-changelog

维护面向人的 CHANGELOG。它记录用户、操作员和发布可见变化，不记录每个 commit。

门控规则输出生命周期

何时需要

当改动影响用户可见行为、公开 API、命令、安装、配置、兼容性、数据、安全、发布说明或操作流程时，changelog gate 应触发并更新 CHANGELOG.md。

分类规则

保持 ## [Unreleased] 在顶部。条目按 Keep a Changelog 分类写入：Added、Changed、Deprecated、Removed、Fixed、Security。内部重构、格式微调、测试 only 和临时过程产物不写入。

输出格式

输出使用 updated、not needed、release prepared 或 blocked 四种形态之一，并说明分类、条目、验证和下一步。

生命周期

CHANGELOG 是长期发布记录，不归档到 plans/audits。版本发布时可以把 Unreleased 条目移动到具体版本；版本号 bump 由发布任务决定。
