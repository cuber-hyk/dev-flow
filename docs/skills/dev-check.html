Skill

dev-check

验证 Dev Flow 文档路由、模板完整性和生命周期健康。它发现结构问题，不替代业务审查。

流程输出规则后续路由

内部流程

Validate
检查插件模板->检查项目 docs
Classify
Errors/Warnings/Recommendations
Route
指向 /dev-initor/dev-distillor/dev-audit

输出格式

输出必须列出 validation result、errors、warnings、recommendations、检查过的范围和下一步。没有问题时也要明确说明验证通过。

状态规则

plan 步骤状态只接受 todo、done、blocked。audit finding 状态只接受 open、planned、resolved、verified。archived audit 中仍有未关闭 finding 时应报错或强警告。

后续路由

缺结构时用 /dev-init skill；active plan/audit 需要关闭时用 /dev-distill skill；需要深度业务审查时用 /dev-audit skill；干净状态下用 /dev-orient skill 开始下一项任务。
