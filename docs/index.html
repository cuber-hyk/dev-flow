让 AI 开发流程 变得可控、可审查、可沉淀

cuberhyk-dev-flow 是一套为 AI Coding 场景设计的工作流插件。 通过 Orient、Plan、Branch、Changelog、Distill 等关键 Gate，帮助你将每一次改动都变成可理解、可验证、可复用的知识。

开始使用 查看工作流

适用于 Claude Code · Codex · Cursor · Gemini · 本地代理

低噪音进入上下文

只读必要文档与关键代码，避免噪音，让 AI 快速进入状态。

审核前闭环

提交与合并前自动完成更新日志与知识沉淀，确保变更可审查、可追溯。

长期知识沉淀

将稳定事实与规则沉淀到 capability 与 ADR，构建可复用的项目文档。

Skills

九个专注技能，各司其职

每个技能只做一件事，职责清晰，配合使用构成完整闭环。

Since 0.7.2, every skill has a dedicated skills/<skill>/templates/output.md response template, audit findings use stable lifecycle fields, and branch work reports changelog, distill, and check gates before review.

dev-init

初始化或补全 Dev Flow 目录与模板，安全接入现有项目。

dev-check

校验文档路由与生命周期规则，发现并修复配置问题。

dev-orient

低噪音进入项目上下文，识别关键文档与代码入口。

dev-plan

识别决策点并制定最小可验证计划，输出可执行计划文档。

dev-audit

审查功能或流程，输出结构化审查报告与改进建议。

dev-exploratory-review

开放式风险发现，先建立项目与风险地图，再报告有真实失败路径的问题。

dev-branch

创建分支实现任务，运行各项 Gate，并等待审核后再提交合并。

dev-changelog

维护 CHANGELOG.md，只记录对用户或运维可见的重要变更。

dev-distill

将稳定事实沉淀到 capability 与 ADR，完成知识闭环。
